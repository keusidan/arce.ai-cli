# 使い方

## 入れる
```bash
cargo install --path .
```
Rust 1.85 以上（edition 2024）。できるのは `arce` 1 つ。設定は `~/.config/arce/`、セッションと秘密は `~/.local/share/arce/`（環境変数 `ARCE_HOME` を入れると、その下の `config/`・`data/` にまとめる）。

## はじめかた
```bash
arce                                   # まずはデモのモデル（ネットワークなし）
arce providers presets                 # 用意された接続先
arce providers add --preset openrouter
arce secrets set openrouter            # キーは画面に出さずに入れる（標準入力からも可）
arce providers models openrouter       # 提供元の /models を見る
arce providers add-model openrouter deepseek/deepseek-chat --context 131072 --max-output 8192
arce config set model "openrouter|deepseek/deepseek-chat"
arce doctor --ping                     # 設定・キー・接続を確かめる
```
この端末のサーバー（`--preset ollama`・`--preset llamacpp`）はキーなしで使える。function calling の無いサーバーは `arce providers add … --text-tools`（`<tool_call>` のテキスト形式）。

## 対話
```bash
arce                     # 対話
arce "テストを直して"     # 最初のメッセージつき
arce -c                  # このフォルダの最後のセッションの続き
arce -r 20261108-081500-1a2b
arce --mode plan         # 読むだけ（計画を出させる）
```
- Enter で送信、行末の `\` で次の行へ、Ctrl-C で返信を止める、Ctrl-D で終わる。
- `@src/main.rs` でファイル（フォルダなら一覧）を添付。`!git status` でシェル（出力は会話に入る）。
- 承認カード：`y` 実行する、`a` この道具は以後聞かない（コマンドと設定の変更には出ない）、`n` やめる（`n テストを先に` のように理由をモデルに返せる）。

| コマンド | 内容 |
|---|---|
| `/model [番号\|provider\|model]` | モデルを替える（この実行の間） |
| `/mode [ask\|auto-edit\|plan\|yolo]` | 承認のモード |
| `/agent [auto\|general\|coding\|research\|artifact\|file-analysis]` | エージェントを固定 |
| `/think [on\|off\|0〜1]` | 思考、速度⇔精度 |
| `/coding [on\|off]` | コーディングモード |
| `/compact`・`/context` | 要約する・トークン数の内訳 |
| `/undo` | 最後に変えたターンのファイルを戻す |
| `/new`・`/sessions [語]`・`/resume [id]`・`/export [file]` | セッション |
| `/add-dir <path>`・`/permissions` | 作業フォルダ・規則 |
| `/settings [key [value]]` | 設定を見る・この実行の間だけ変える |
| `/mcp`・`/memory <文>`・`/init`・`/status`・`/help`・`/exit` | |

**自作のコマンド**：`.arce/commands/<名前>.md`（プロジェクト）か `~/.config/arce/commands/<名前>.md` を置くと `/名前` で送れる。`$ARGUMENTS` に引数が入る（無ければ末尾に足す）。先頭の `---` の間に `description:` を書くと `/help` に出る。

## 非対話（スクリプト・CI）
```bash
arce -p "README の誤字を直して" --mode auto-edit
git diff | arce -p "この差分をレビューして" --output-format json
arce -p "テストを流して結果をまとめて" --allow "run_command(cargo test*)" --output-format stream-json
```

## 設定の例（`~/.config/arce/settings.toml`）
```toml
model = "openrouter|deepseek/deepseek-chat"
mode = "ask"
tone = "短く、敬語で"

[limits]
max_tool_rounds = 30
command_timeout_secs = 120

[permissions]
allow = ["run_command(cargo test*)", "run_command(git status*)", "run_command(git diff*)"]
deny = ["run_command(rm -rf *)", "run_command(git push*)"]
http_confirm = "with_secrets"   # always / with_secrets / never

[ui]
show_thinking = "summary"       # full / summary / hidden
code_fold_lines = 40

[[providers]]
id = "openrouter"
base_url = "https://openrouter.ai/api/v1"
prompt_cache = false

[[providers.models]]
id = "deepseek/deepseek-chat"
context_tokens = 131072
max_output_tokens = 8192
thinking = { format = "openrouter" }

[[fallback]]
from = "openrouter|*"
targets = ["deepseek|deepseek-chat"]

[coding]
enabled = true
developers = ["openrouter|deepseek/deepseek-chat", "ollama|llama3.1:8b"]
max_tasks = 8
parallel = 4

[[mcp.servers]]
id = "github"
command = "github-mcp-server"
args = ["stdio"]
env = { GITHUB_PERSONAL_ACCESS_TOKEN = "{{secret:github}}" }
enabled = true

[[hooks]]
event = "post_tool"
matcher = "edit_file"
command = "cargo fmt >/dev/null 2>&1 || true"
```
すべての項目と既定値は `arce config list`、1 つずつは `arce config get limits.max_tool_rounds` / `arce config set limits.max_tool_rounds 50`（`--project` でプロジェクトの `.arce/settings.toml`）。

## 秘密を道具で使う
```bash
arce secrets set weather --host api.weather.example
```
モデルは `http_request` で `https://api.weather.example/v1?key={{secret:weather}}` のように書く。値はモデルにも画面にも出ず、`api.weather.example` 以外には送られない。
