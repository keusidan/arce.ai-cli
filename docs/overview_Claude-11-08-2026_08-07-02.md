# 概要・ディレクトリ・作業のルール

現行の仕様だけを書く（0.1.0 時点）。リポジトリ：`keusidan/arce.ai-cli`。

## 何のツールか
ARCE.AI（`keusidan/arce.ai`、Flutter 製のローカル AI チャット / コーディングアシスタント）を、**ターミナルで使う CLI(Command Line Interface)** にしたもの。Rust 製の 1 つの実行ファイル `arce`。

- 対話（REPL(Read-Eval-Print Loop)）と非対話（`arce -p "…"`、出力は text / json / stream-json）の 2 つの入口。
- モデルは OpenAI 互換の chat-completions の窓口ならどれでも（クラウドの提供元、この端末の Ollama・llama.cpp server など）。プロバイダを設定するまでは、ネットワークを使わない**デモのモデル**が答える（アプリの `DemoEngine` と同じ考え）。
- 作業フォルダのファイルを読み書きし、コマンドを動かし、HTTP を送る道具を持つ。危ない操作は承認のモードと規則で止める。
- デザイン（色のトークン・返信の見え方）と独自の処理（エージェントの選び方・会話の圧縮・秘密の扱い・分担・フォールバック・エラーの分類など）は arce.ai から受け継いだ（`arce_heritage`）。
- 機能の作りは、公開されている AI CLI 10 種の調査（`cli_survey`）を参考にした。**参考にしたツールの名前・出典はリポジトリに書かない**（利用者の指示）。

## ディレクトリ

| 場所 | 内容 |
|---|---|
| `src/main.rs` | 入口：引数（clap）、非対話モード、サブコマンド（`config`・`providers`・`secrets`・`sessions`・`trust`・`doctor`） |
| `src/app.rs` | 設定と引数から `Controller` を組み立てる。自作コマンドの読み込み |
| `src/repl.rs` | 対話のループ（rustyline）、スラッシュコマンド、`!コマンド` |
| `src/controller.rs` | 1 つの会話：返信のループ、道具の実行と承認、フォールバック、圧縮、分担、設定の変更 |
| `src/llm.rs` | 会話の形（`Message`）と、OpenAI 互換の窓口へのストリーミング（SSE(Server-Sent Events) の読み取り、道具の呼び出しの組み立て、デモのモデル） |
| `src/segmenter.rs` | 流れてくる文字を、思考（`<think>`）・本文・テキスト形式の道具の呼び出し（`<tool_call>`）に分ける |
| `src/provider.rs` | プロバイダとモデルの設定、思考の送り方、フォールバックの規則、失敗の分類（日本語の理由）、プリセット |
| `src/settings.rs` | 設定（TOML）、プロジェクトの設定と信頼、チャットから変えられる設定の一覧 |
| `src/permissions.rs` | 承認のモードと規則、コマンドの分解、パスの解決 |
| `src/tools.rs` | 組み込みの道具（定義・承認カードの中身・実行） |
| `src/secrets.rs` | 秘密の保存、`{{secret:ID}}`、送ってよいホストの検査、伏せ字 |
| `src/session.rs` | セッション（JSONL）、取り消し用の控え（チェックポイント）、検索、Markdown への書き出し |
| `src/compaction.rs` | 長い会話の圧縮（純粋な部分） |
| `src/plan_graph.rs` | Mermaid の flowchart の読み取り（分担の依存） |
| `src/delegation.rs` | コーディングモードの `delegate`（開発モデルへの並列の割り振り） |
| `src/agents.rs` | エージェント（役割）と、その選び方 |
| `src/prompt.rs` | システムプロンプト（時刻を入れない）、指示ファイルの読み込み、分担の指示 |
| `src/mcp.rs` | MCP(Model Context Protocol) サーバー（stdio） |
| `src/hooks.rs` | フック |
| `src/markdown.rs` | 端末向けの Markdown（ストリーミング） |
| `src/theme.rs` | 色のトークン（アプリと同じ値） |
| `src/ui.rs` | 画面（端末・JSON）、承認カード、集計の行 |
| `tests/e2e.rs` | 偽の OpenAI 互換サーバーに対して、実行ファイルを端から端まで動かすテスト |
| `docs/` | このフォルダ |

## 作業のルール（利用者の指定）
`AGENTS.md`（英語）に、エージェント向けの約束と利用者の指示がまとまっている。ここでは背景だけを書く。
- 作業は `dev` ブランチで行う（利用者の指示）。
- 参考にした CLI ツールの出典（名前・URL・配布元）は、リポジトリのどこにも書かない（著作権などの問題を避けるため。利用者の指示）。コード・文章・デザインは写さず、すべて独自に書く。
- デザインと独自の処理は `keusidan/arce.ai` から取ってくる。色のトークンを変えるときは、アプリの `lib/ui/theme.dart` と同じ値に保つ。
- エージェントに必要なこと・利用者から追加で指示されたことは、`AGENTS.md` に**英語で**書く（利用者の指示）。
- 言語の指定がなければ Rust で、最適化されたコードで書く。Python は代わりがあれば使わない。
- 新しく作る docs のファイル名には、拡張子の前に `Claude-MM-dd-yyyy_HH-mm-ss`（日本時間）を付ける。例外：ツールや規約が名前で読むもの（`AGENTS.md`・`README.md`・`Cargo.toml`・`.gitignore` など）、Rust のソース（モジュール名がファイル名で決まる）、既存ファイルの編集。
- 返答は日本語。略称は初出で「略称(正式名称)」。英語由来の技術用語は英単語のまま。
- PR は頼まれるまで作らない。

## ブランチ

- `claude/arce-ai-cli-dev-druxxk`：このセッションの作業ブランチ（`dev` と同じ内容を push する）。
- `main` はまだ無い（最初のリリースを決めるときに、利用者が決める）。
